# Quantum Earth

Real-time 3D aerospace intelligence and tracking platform with voice AI.

## Features
- 3D globe visualization for aircraft, satellites, and rockets
- Live data feeds with layered visualizations
- AI insights panel and voice copilot
- Supabase-backed services and Edge Functions

## Quick Start
```bash
npm install
npm run dev
```

Open `http://localhost:8081/app` if port 8080 is busy.

## Notes
- Requires environment variables in `.env` (not committed).
- LiveKit and xAI voice integrations are configurable via Supabase functions.
